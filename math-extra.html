🔢 คณิตศาสตร์เพิ่มเติม

เจาะลึกคณิตศาสตร์ระดับสูง เซต ตรรกศาสตร์ ฟังก์ชัน และตรีโกณมิติ

บทที่ 1: เซต (Sets)

เซต (Set) คือกลุ่มของสิ่งต่างๆ ที่ระบุได้ชัดเจนว่ามีสมาชิกอะไรบ้าง เซตเป็นรากฐานสำคัญของคณิตศาสตร์สมัยใหม่ ใช้อธิบายแนวคิดเรื่องกลุ่ม ความสัมพันธ์ และตรรกะ

📚 ที่มาของทฤษฎีเซต

ทฤษฎีเซตถูกคิดค้นโดย Georg Cantor (เกออร์ก คันทอร์) นักคณิตศาสตร์ชาวเยอรมัน ในปี ค.ศ. 1874 เขาใช้แนวคิดเซตเพื่ออธิบาย "อนันต์" (infinity) และพิสูจน์ว่า "อนันต์" มีหลายขนาด - จำนวนจริงมี "มากกว่า" จำนวนนับ ถึงแม้ทั้งสองจะมีจำนวนสมาชิกเป็นอนันต์!

📝 การเขียนเซต

📊 3 วิธีเขียนเซต

🔶 การดำเนินการบนเซต

📊 แผนภาพเวนน์ (Venn Diagram)

💡 ตัวอย่าง

❓ ให้ A = {1,2,3,4,5} และ B = {3,4,5,6,7} จงหา A∪B, A∩B, A-B
1 A ∪ B = {1,2,3,4,5,6,7} (รวมสมาชิกทั้งหมด ไม่ซ้ำ)
2 A ∩ B = {3,4,5} (สมาชิกที่อยู่ทั้งสองเซต)
3 A - B = {1,2} (สมาชิกใน A ที่ไม่อยู่ใน B)

บทที่ 2: ฟังก์ชัน (Functions)

ฟังก์ชัน (Function) คือ "เครื่องจักร" ที่รับค่า input แล้วให้ค่า output ออกมา โดยค่า input แต่ละค่าจะให้ output ได้เพียงค่าเดียวเท่านั้น

📚 ที่มาของฟังก์ชัน

คำว่า "Function" ถูกใช้ครั้งแรกโดย Gottfried Wilhelm Leibniz (ไลบ์นิซ) ในปี ค.ศ. 1694 เขามองว่าฟังก์ชันคือ "ปริมาณที่ขึ้นอยู่กับเส้นโค้ง" ต่อมา Leonhard Euler (ออยเลอร์) ได้พัฒนาสัญลักษณ์ f(x) ที่เราใช้กันทุกวันนี้ ในปี ค.ศ. 1748

📊 ฟังก์ชันคือ "เครื่องจักร"

ใส่ x เข้าไป → ฟังก์ชันประมวลผล → ได้ผลลัพธ์ออกมา (input 1 ตัว ได้ output เพียง 1 ค่า)

ประเภทของฟังก์ชัน

ประเภท รูปแบบ ตัวอย่าง ลักษณะกราฟ
ฟังก์ชันเชิงเส้น f(x) = ax + b f(x) = 2x + 1 เส้นตรง
ฟังก์ชันกำลังสอง f(x) = ax² + bx + c f(x) = x² - 4 พาราโบลา
ฟังก์ชันค่าสัมบูรณ์ f(x) = |x| f(x) = |x - 2| รูปตัว V

📊 กราฟฟังก์ชันกำลังสอง f(x) = x²

กราฟพาราโบลาเปิดขึ้น เพราะสัมประสิทธิ์ของ x² เป็นบวก

บทที่ 3: ตรีโกณมิติ (Trigonometry)

ตรีโกณมิติ แปลตรงตัวว่า "การวัดสามเหลี่ยม" (Tri = สาม, Gono = มุม, Metry = การวัด) เป็นการศึกษาความสัมพันธ์ระหว่างด้านและมุมของสามเหลี่ยม

📚 ที่มาของตรีโกณมิติ

ตรีโกณมิติมีต้นกำเนิดจากอียิปต์โบราณและบาบิโลน ที่ใช้คำนวณมุมเพื่อสร้างพีระมิดและสังเกตดวงดาว ต่อมานักคณิตศาสตร์กรีก ฮิปพาร์คัส (Hipparchus, 190-120 ปีก่อนคริสตกาล) ได้สร้างตารางตรีโกณมิติแรกของโลก จนได้รับสมญานามว่า "บิดาแห่งตรีโกณมิติ"

🔸 อัตราส่วนตรีโกณมิติพื้นฐาน

📊 สามเหลี่ยมมุมฉากและอัตราส่วนตรีโกณมิติ

SOH: Sin = Opposite/Hypotenuse | CAH: Cos = Adjacent/Hypotenuse | TOA: Tan = Opposite/Adjacent

💡 เคล็ดลับจำ SOH CAH TOA

ลองจำเป็นวลี: "Some Old Horse Caught Another Horse Taking Oats Away" หรือจำเป็นภาษาไทย: "ซ้อ (SOH) ก้า (CAH) โต้ (TOA)"

🔸 มุมพิเศษที่ต้องจำ

มุม θ 0° 30° 45° 60° 90°
sin θ 0 1/2 √2/2 √3/2 1
cos θ 1 √3/2 √2/2 1/2 0
tan θ 0 √3/3 1 √3 undefined

🤔 ทำไม sin 30° = 1/2 ?

ลองนึกภาพสามเหลี่ยมมุมฉากที่มีมุม 30°-60°-90° ถ้าด้านตรงข้ามมุมฉาก (hypotenuse) = 2 หน่วย แล้วด้านตรงข้ามมุม 30° จะยาว = 1 หน่วยพอดี (ครึ่งหนึ่งของด้านเอียง) ดังนั้น sin 30° = 1/2 = 0.5 ลองวาดภาพดู จะเข้าใจมากขึ้น!

💡 ตัวอย่าง: หาความสูงอาคาร

❓ ยืนห่างจากอาคาร 50 เมตร วัดมุมเงย = 60° อาคารสูงเท่าไร?
1 ด้านประชิด (adjacent) = 50 m, ต้องการหาด้านตรงข้าม (opposite) = ความสูง
2 ใช้ tan: tan 60° = opposite/adjacent → √3 = h/50
3 h = 50√3 ≈ 50 × 1.732 = 86.6 m
✓ คำตอบ: อาคารสูงประมาณ 86.6 เมตร
